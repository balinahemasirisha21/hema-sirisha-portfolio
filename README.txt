# B. Hema Sirisha - Portfolio

## Open in VS Code

1. Extract the `Hema_Sirisha_Portfolio.zip` file.
2. Open the extracted `Hema_Sirisha_Portfolio` folder in VS Code.
3. Open `index.html`.
4. Use the Live Server extension and click **Go Live**.
5. The portfolio will open in your browser.

## Files

- `index.html` - portfolio structure/content
- `style.css` - complete responsive styling
- `script.js` - navigation, scroll reveal and project pop-up details
- `assets/profile.jpg` - profile photo
- `Hema_Sirisha_Resume.pdf` - resume

## Easy updates

Most personal information is inside `index.html`.
Project pop-up descriptions are inside `script.js`.
Colors, spacing and layout are inside `style.css`.

The Google Photos album is included as a Photo Album button. The profile photo in the portfolio is the image supplied directly in this chat.
